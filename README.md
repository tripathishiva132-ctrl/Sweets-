# Shiv Shakti Sweets & Namkeen — Website files

## Files
- `index.html` — Home page
- `sweets.html` — Sweets category
- `namkeen.html` — Namkeen category
- `gifting.html` — Gift hampers
- `about.html` — Our story
- `contact.html` — Contact and map link
- `cart.html` — Cart and WhatsApp order form
- `admin.html` — Front-end admin demo
- `assets/style.css` — All styling
- `assets/app.js` — Cart, product and demo admin logic

## Run locally
Open `index.html` in a browser. Keep the `assets` folder beside the HTML files.

## Publish
Upload the HTML files, README and the complete `assets` folder to the root of a public GitHub repository. Do not upload only the ZIP.

## Important production notes
This is a front-end starter/demo. Admin data is stored in browser localStorage, so it is not a secure multi-device admin system. The current demo password is `AbhinavTripathi`; change/remove it before public launch. WhatsApp ordering opens a pre-filled message to the shop number configured in `assets/app.js`. Confirm the number before publishing. For a real shared admin panel, connect a secure backend/database with authentication and access rules.
